# Launcher-Simulador

Proyecto de prácticas Medac.  
Este launcher permite comprobar versiones, descargar actualizaciones y mostrar noticias del juego.  

## Funcionalidades previstas
- Actualización automática desde CDN
- Verificación de integridad con SHA-256
- Rollback en caso de error
- Interfaz básica con botón JUGAR y sección de noticias

## Requisitos
- Lenguaje: C# (.NET / Visual Studio)  
- Hosting: CDN para versiones y manifest.json  
- Sistema operativo: Windows 10/11
